**Branch**: `017-e4-attacker-update` | **Date**: 2026-07-10 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/017-e4-attacker-update/spec.md`

## Summary

Implement `LinUCBModel` in `src/aatf/linucb.py` — a contextual-bandit attacker that maintains per-action belief records (A_inv, b) and learns which attack actions evade detection. Per step: `update(action_id, context, reward)` applies the Sherman-Morrison rank-1 update; `select_action(available, context)` returns the highest-UCB action (ties broken alphabetically). State is fully serialisable via `to_dict()` / `from_dict()`.

Context vector dimension: **d = 50** (from `build_context()` in F13). Tests use d=1 and d=2 for analytic tractability.

## Constitution Check

### Principle I — Safety & Isolation First (NON-NEGOTIABLE)

✅ **PASS**. LinUCBModel is pure in-memory math — no network access, no file I/O, no lab traffic. It does not touch the action executor or the defence. It computes scores and updates arrays. No safety concern.

### Principle II — Reproducibility & Determinism (NON-NEGOTIABLE)

✅ **PASS**. `update()` and `select_action()` are deterministic functions of their inputs — no randomness of their own. The exploration bonus `alpha * sqrt(context @ A_inv @ context)` is a deterministic function of the belief and context. The full model state is exportable via `to_dict()`, enabling exact reproduction from a run manifest. Given the same seed-controlled context inputs, identical output is guaranteed.

### Principle III — Pluggable Defence Interface (NON-NEGOTIABLE)

✅ **PASS**. LinUCBModel is a pure attacker component — it does not depend on `Defence` at all. It consumes `reward: float` (a scalar) and `context: np.ndarray` — both are agnostic to which defence produced the detection signal.

### Principle IV — Scientific Validity & Test-First

✅ **PASS**. 10 contracts written before implementation. SC-001 (analytic ground truth for A_inv after one Sherman-Morrison step, tolerance < 1e-9) locks the core math. SC-002/SC-003 lock selection correctness and tie-breaking. SC-004/SC-005 lock serialisation. Tests use `d=1` and `d=2` for exact hand-computable expected values — no approximation.

### Principle VI — Observability & Honest Feedback

✅ **PASS**. F17 consumes the reward signal computed by F14 (`compute_reward()`) and produced by F16 (`run_episode()`). It does not modify or smooth the reward. `to_dict()` exposes full model state for post-experiment analysis.

## Architecture

### `src/aatf/linucb.py` (complete implementation)

```python
"""LinUCB contextual-bandit attacker — per-action belief update and UCB selection."""

from __future__ import annotations

import math

import numpy as np


class LinUCBModel:
    def __init__(
        self,
        d: int,
        alpha: float = 1.0,
        *,
        _arms: dict[str, tuple[np.ndarray, np.ndarray]] | None = None,
    ) -> None:
        self.d = d
        self.alpha = alpha
        self._arms: dict[str, tuple[np.ndarray, np.ndarray]] = _arms if _arms is not None else {}

    def _get_or_init_arm(self, action_id: str) -> tuple[np.ndarray, np.ndarray]:
        if action_id not in self._arms:
            self._arms[action_id] = (np.eye(self.d, dtype=float), np.zeros(self.d, dtype=float))
        return self._arms[action_id]

    def update(self, action_id: str, context: np.ndarray, reward: float) -> None:
        A_inv, b = self._get_or_init_arm(action_id)
        x = A_inv @ context
        A_inv = A_inv - np.outer(x, x) / (1.0 + float(context @ x))
        b = b + reward * context
        self._arms[action_id] = (A_inv, b)

    def select_action(self, available: list[str], context: np.ndarray) -> str:
        best_id = sorted(available)[0]
        best_score = float("-inf")
        for action_id in sorted(available):
            A_inv, b = self._get_or_init_arm(action_id)
            theta = A_inv @ b
            score = float(theta @ context) + self.alpha * math.sqrt(
                max(0.0, float(context @ A_inv @ context))
            )
            if score > best_score:
                best_score = score
                best_id = action_id
        return best_id

    def to_dict(self) -> dict:
        return {
            "d": self.d,
            "alpha": self.alpha,
            "arms": {
                action_id: {"A_inv": A_inv.tolist(), "b": b.tolist()}
                for action_id, (A_inv, b) in self._arms.items()
            },
        }

    @classmethod
    def from_dict(cls, data: dict) -> LinUCBModel:
        arms = {
            action_id: (
                np.array(arm["A_inv"], dtype=float),
                np.array(arm["b"], dtype=float),
            )
            for action_id, arm in data.get("arms", {}).items()
        }
        return cls(d=data["d"], alpha=data["alpha"], _arms=arms)
```

**Note on `max(0.0, ...)` in `select_action`**: floating-point rounding can produce a tiny negative value for `context @ A_inv @ context` after many updates; `max(0.0, ...)` guards `sqrt` against a domain error without affecting correctness.

## Complexity Tracking

| Risk | Mitigation |
|------|-----------|
| Float precision in sqrt domain | `max(0.0, ...)` guard — covered by test with many updates |
| dtype inconsistency (float32 context from F13 vs float64 internal) | numpy promotion rules handle it; internal dtype always float64 |
| `_arms` passed as kwarg constructor injection | `_arms` is keyword-only with `None` default — not part of the public interface |
