# Implementation Plan: Context Vector Builder (F13)

**Branch**: `013-e4-context-vector` | **Date**: 2026-07-10 | **Spec**: specs/013-e4-context-vector/spec.md

## Summary

Build `build_context(episode_state, current_time=None) -> np.ndarray` — a pure, deterministic function that encodes an `EpisodeState` into a 50-element float32 numpy array (the RL attacker's observation). Five feature families in fixed layout: alert_history (10), attack_progress (15), technique_history (15), timing (2), rule_category_fired (8). `CONTEXT_DIM = 50` is the authoritative shape constant for downstream RL policy code. No I/O. Stdlib + numpy only.

## Architecture

### EpisodeState dataclass

```text
@dataclass
class EpisodeState:
    completed_actions: set[str]           # validated against REGISTRY in __post_init__
    detection_history: dict[str, list[bool]]
    alert_history: list[bool]
    step: int                             # validated >= 0
    start_time: float
    fired_categories: set[str]
```

### build_context

```text
def build_context(
    episode_state: EpisodeState,
    current_time: float | None = None,
) -> np.ndarray:  # shape=(50,), dtype=float32
```

Assembly order:
1. `alert = _build_alert_history(episode_state.alert_history)`   → shape (10,)
2. `progress = _build_attack_progress(episode_state.completed_actions)`  → shape (15,)
3. `technique = _build_technique_history(episode_state.detection_history)`  → shape (15,)
4. `timing = _build_timing(episode_state.step, episode_state.start_time, current_time)`  → shape (2,)
5. `cats = _build_rule_categories(episode_state.fired_categories)`  → shape (8,)
6. `return np.concatenate([alert, progress, technique, timing, cats]).astype(np.float32)`

### Helper functions (private)

| Helper | Input | Output shape | Key logic |
|--------|-------|-------------|-----------|
| `_build_alert_history` | `list[bool]` | (10,) | take last 10, pad left with 0 |
| `_build_attack_progress` | `set[str]` | (15,) | 1.0 if id in set |
| `_build_technique_history` | `dict[str, list[bool]]` | (15,) | detected/total; 0.0 if empty |
| `_build_timing` | step, start_time, current_time | (2,) | clip(step/100), clip(elapsed/3600) |
| `_build_rule_categories` | `set[str]` | (8,) | 1.0 if category in ET_CATEGORIES |
