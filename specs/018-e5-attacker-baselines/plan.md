## Summary

Implement `Attacker` abstract base class and three concrete implementations in `src/aatf/attacker.py`:
- `RandomAttacker` — seeded uniform-random selection, no-op observe
- `FixedScriptAttacker` — deterministic round-robin cycle, default alphabetical sort, no-op observe
- `LinUCBAttacker` — thin adapter delegating to `LinUCBModel.select_action` / `LinUCBModel.update`

All four are importable from `aatf.attacker`. Pure in-memory, no file I/O. 12 TDD contracts in `tests/test_attacker.py`.

## Constitution Check

### Principle I — Safety & Isolation First (NON-NEGOTIABLE)

✅ **PASS**. `Attacker` and all implementations are pure in-memory policy objects — no network access, no file I/O, no lab traffic, no subprocess. They do not touch the action executor or emit any traffic. `LinUCBAttacker` delegates only to `LinUCBModel`, which is also pure in-memory math.

### Principle II — Reproducibility & Determinism (NON-NEGOTIABLE)

✅ **PASS**. `RandomAttacker` uses a seeded `random.Random` instance; identical seed → identical sequence (SC-002). `FixedScriptAttacker` is fully deterministic from its script. `LinUCBAttacker` is deterministic given model state and context. No global state is mutated.

### Principle III — Pluggable Defence Interface (NON-NEGOTIABLE)

✅ **PASS**. `Attacker` is a separate interface from `Defence` (F10). This feature is purely on the attacker side — no dependency on any `Defence` subclass. The episode loop (F16/F20+) wires them together; they remain decoupled here.

### Principle IV — Scientific Validity & Test-First

✅ **PASS**. 12 contracts written before implementation (C-001..C-012). SC-002 (seeded determinism) verified empirically before contract authoring. SC-004 (LinUCBAttacker delegation) tested by inspecting `model._arms` directly after `observe` — same ground truth as spec-017 C-002.

### Principle VI — Observability & Honest Feedback

✅ **PASS**. `LinUCBAttacker.observe` delegates faithfully to `LinUCBModel.update`; no reward smoothing or interception. `RandomAttacker.observe` and `FixedScriptAttacker.observe` are explicit no-ops (documented, not silently hidden).

### Principle VII — Phased Delivery Behind a Hard Gate

✅ **PASS**. F18 is Phase 1 (E5). No Phase 2 features introduced. Episode wiring (F20+), serialisation (F19+), evaluation harness (F20+), Q-learning (F19) all explicitly out of scope.

## Architecture

### `src/aatf/attacker.py` (complete implementation)

```python
"""Attacker policy interface and baseline implementations."""

from __future__ import annotations

import itertools
import random
from abc import ABC, abstractmethod
from collections.abc import Iterator

import numpy as np

from aatf.linucb import LinUCBModel


class Attacker(ABC):
    @abstractmethod
    def choose_action(self, available: list[str], context: np.ndarray) -> str: ...

    @abstractmethod
    def observe(self, action_id: str, context: np.ndarray, reward: float) -> None: ...


class RandomAttacker(Attacker):
    def __init__(self, seed: int = 0) -> None:
        self._rng = random.Random(seed)

    def choose_action(self, available: list[str], context: np.ndarray) -> str:
        if not available:
            raise ValueError("available must be non-empty")
        return self._rng.choice(available)

    def observe(self, action_id: str, context: np.ndarray, reward: float) -> None:
        pass


class FixedScriptAttacker(Attacker):
    def __init__(self, script: list[str] | None = None) -> None:
        self._script: list[str] | None = script
        self._cycle: Iterator[str] | None = None

    def choose_action(self, available: list[str], context: np.ndarray) -> str:
        if self._cycle is None:
            if self._script is None:
                self._script = sorted(available)
            self._cycle = itertools.cycle(self._script)
        return next(self._cycle)

    def observe(self, action_id: str, context: np.ndarray, reward: float) -> None:
        pass


class LinUCBAttacker(Attacker):
    def __init__(self, model: LinUCBModel) -> None:
        self._model = model

    def choose_action(self, available: list[str], context: np.ndarray) -> str:
        return self._model.select_action(available, context)

    def observe(self, action_id: str, context: np.ndarray, reward: float) -> None:
        self._model.update(action_id, context, reward)
```

### Test strategy (`tests/test_attacker.py`)

- No REGISTRY, ATTACK_GRAPH, or episode loop — pure unit tests
- d=1 context (`np.zeros(1)` or `np.array([1.0])`) for all tests
- `LinUCBModel(d=1)` for `LinUCBAttacker` tests — avoids importing CONTEXT_DIM
- C-007 (no-op observe) tests RNG sequence unaffected by `observe` intercall

## Complexity Tracking

| Risk | Mitigation |
|------|-----------|
| `FixedScriptAttacker` default-script locked on first call only | Verified: `_cycle is None` guard; subsequent calls always use stored `_cycle` |
| `C-007` (observe no-op) test subtle — must show RNG is not advanced | Compare 3rd call of `r1` (with observe between calls 1 and 2) vs 3rd call of `r2` (no observe). Both use same seed, same number of `choose_action` calls → same result. |
| `LinUCBAttacker.choose_action` may mutate model via lazy init | `select_action` calls `_get_or_init_arm` which adds arms to `_arms` as side-effect. Acceptable — documented in data-model.md. Tests account for this. |
| ruff `UP006`/`UP035` on `list[str]` annotation | Use `from __future__ import annotations` + `list[str]` (not `List[str]`) — consistent with rest of codebase. |
