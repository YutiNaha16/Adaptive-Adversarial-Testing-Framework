# Implementation Plan: Episode Loop (F16)

**Branch**: `016-e4-episode-loop` | **Date**: 2026-07-10 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/016-e4-episode-loop/spec.md`

## Summary

Implement `run_episode()` in `src/aatf/episode.py` — the central orchestrator that drives one attack episode end-to-end. Per-step: check available (uncompleted reachable) actions, check step limit (no-actions check first per FR-003), select action, execute, call `defence.observe()` with a constructed `Action`, extract `alert_fired` + `suricata_category` from `REGISTRY`, call `collect_feedback()`, call `compute_reward()`, append `StepRecord`. Return `EpisodeResult`.

Key correction from spec: the `Defence` interface is `observe(action: Action) -> DetectionResult` (not `detect(action_id) -> (bool, str|None)`). F16 must construct the `Action` from `REGISTRY.get_action(action_id)` before calling `observe()`.

Key correction on available_actions: `AttackGraph.available_actions()` returns ALL reachable (including completed). F16 must filter: `[a for a in reachable if a not in episode_state.completed_actions]`.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

### Principle I — Safety & Isolation First (NON-NEGOTIABLE)

✅ **PASS**. F16 is a pure orchestration layer with no I/O, no network access. The `execute_fn` is injected by the caller — F16 does not call the ActionExecutor directly and does not know its implementation. All safety constraints (lab-internal-only, defanged traffic) are enforced at the F11 layer, not here. `defence.observe()` is called on the injected Defence instance — no Suricata-specific coupling.

### Principle II — Reproducibility & Determinism (NON-NEGOTIABLE)

✅ **PASS**. `run_episode` is deterministic given a fixed `action_selector` and `defence` stub. The only non-reproducible element is `datetime.now(timezone.utc)` used in constructing the `Action` timestamp — acceptable because timestamps are ephemeral step metadata, not used in reward, context vector, or metrics computation. The selector (LinUCB/rng) is injected; seeding is the caller's responsibility.

### Principle III — Pluggable Defence Interface (NON-NEGOTIABLE)

✅ **PASS**. F16 depends only on the `Defence` ABC (`observe(action: Action) -> DetectionResult`). `NullDefence`, `SuricataDefence`, and any Phase 2 ML detector are all drop-in substitutes. No Suricata-specific code in F16.

### Principle IV — Scientific Validity & Test-First

✅ **PASS**. 12 contracts written before implementation (see `contracts/episode-contract.md`). Contracts cover single-step correctness, both termination paths, the FR-003 priority ordering, and cumulative reward accuracy. Tests use real ATTACK_GRAPH and real REGISTRY ids — no synthetic fakes.

### Principle VI — Observability & Honest Feedback

✅ **PASS**. F16 faithfully threads the reward signal from `compute_reward(detected, stage_progress)` into each `StepRecord`. Total reward is a plain arithmetic sum — no smoothing, clamping, or modification. `EpisodeResult.steps` provides a complete ordered trace.

### Principle VII — Phased Delivery Behind a Hard Gate

✅ **PASS**. F16 is Phase 1 scope (E4 Feedback Loop). No Phase 2 features introduced. Episode logging to disk (F19+) and multi-episode harness (F20+) are explicitly out of scope.

## Architecture

### `src/aatf/episode.py` (complete implementation)

```python
"""Episode loop — orchestrates a single attack episode end-to-end."""

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timezone
from typing import Callable

from aatf.action_library import REGISTRY
from aatf.attack_graph import ATTACK_GRAPH, AttackGraph
from aatf.context_vector import EpisodeState, MAX_STEPS
from aatf.contracts import Action
from aatf.defence import Defence
from aatf.feedback import collect_feedback
from aatf.reward import compute_reward


@dataclass(frozen=True)
class StepRecord:
    action_id: str
    detected: bool
    stage_progress: bool
    reward: float


@dataclass(frozen=True)
class EpisodeResult:
    episode_state: EpisodeState
    steps: list[StepRecord]
    total_reward: float
    completed: bool


def run_episode(
    episode_state: EpisodeState,
    action_selector: Callable[[list[str], EpisodeState], str],
    execute_fn: Callable[[str], None],
    defence: Defence,
    *,
    attack_graph: AttackGraph = ATTACK_GRAPH,
    max_steps: int = MAX_STEPS,
) -> EpisodeResult:
    steps: list[StepRecord] = []
    total_reward = 0.0

    while True:
        reachable = attack_graph.available_actions(episode_state.completed_actions)
        available = [a for a in reachable if a not in episode_state.completed_actions]

        # FR-003: no-actions check BEFORE step-limit check
        if not available:
            return EpisodeResult(
                episode_state=episode_state,
                steps=steps,
                total_reward=total_reward,
                completed=True,
            )
        if episode_state.step >= max_steps:
            return EpisodeResult(
                episode_state=episode_state,
                steps=steps,
                total_reward=total_reward,
                completed=False,
            )

        action_id = action_selector(available, episode_state)
        execute_fn(action_id)

        action_def = REGISTRY.get_action(action_id)
        action = Action(
            action_id=action_id,
            category=action_def.category,
            parameters=action_def.default_parameters,
            timestamp=datetime.now(timezone.utc),
        )
        detection = defence.observe(action)
        alert_fired = detection.alerted
        category = action_def.suricata_category if alert_fired else None

        result = collect_feedback(
            episode_state, action_id, alert_fired,
            attack_graph=attack_graph, category=category,
        )
        reward = compute_reward(result.detected, result.stage_progress)
        steps.append(
            StepRecord(
                action_id=action_id,
                detected=result.detected,
                stage_progress=result.stage_progress,
                reward=reward,
            )
        )
        total_reward += reward
```

### Test strategy (`tests/test_episode.py`)

- **StubDefence**: concrete subclass of `Defence` with `__init__(alert: bool)` and `observe()` returning `DetectionResult(alerted=alert, ...)`
- **`_SELECTOR`**: `lambda available, state: available[0]` (picks alphabetically first — deterministic)
- **`_EXECUTE`**: `lambda action_id: None` (no-op)
- **`_ALL_IDS`**: `frozenset(a.action_id for a in REGISTRY.list_actions())` — all 15 ids
- **No custom AttackGraph** — use real `ATTACK_GRAPH` (mutable graph constraint from F09)
- **Terminal action for no-progress / 1-remaining tests**: `ssh_version_probe` (no outgoing edges; always reachable via `icmp_ping_sweep` entry point)
- **Setup for single-remaining-action**: `EpisodeState(completed_actions=set(_ALL_IDS - {"ssh_version_probe"}))`

12 contracts cover: StepRecord fields (C-001 to C-005), termination paths (C-006 to C-010), cumulative result (C-011 to C-012).

## Complexity Tracking

| Risk | Mitigation |
|------|-----------|
| `available_actions` includes completed ids | Explicit filter `if a not in episode_state.completed_actions` — covered by C-006/C-007 |
| Defence interface mismatch vs spec assumption | Documented in research.md; real `observe()` used; spec assumption superseded |
| Mutable `EpisodeState` in frozen `EpisodeResult` | Acceptable — the field reference is frozen; the referenced object is mutable by design |
| `datetime.now()` in step construction | Non-reproducible timestamps; excluded from all metric computation; not tested |
