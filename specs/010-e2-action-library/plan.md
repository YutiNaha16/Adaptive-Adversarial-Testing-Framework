# Implementation Plan: Defanged Action Library (F07)

**Branch**: `010-e2-action-library` | **Date**: 2026-07-06 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/010-e2-action-library/spec.md`

## Summary

Build a static, in-memory library of ≥15 defanged attack `ActionDefinition` objects organised into a typed `ActionRegistry`, plus a `safety_guard()` function that enforces Constitution Principle I (no external IPs, no empty parameters). All definitions live in `src/aatf/action_library.py`. No network I/O, no subprocess, no new pip dependencies. Unit tests are pure in-memory — no Docker, no fixtures directory.

## Technical Context

**Language/Version**: Python 3.12 (pinned per F01)
**Primary Dependencies**: stdlib only — `dataclasses`, `ipaddress`, `typing`; Pydantic V2 (already in `.venv`) for `Action` contract via F03
**Storage**: N/A — pure in-memory module-level constant
**Testing**: pytest (already configured)
**Target Platform**: Linux (lab host), runs inside or outside Docker
**Project Type**: Single Python package (`src/aatf/`)
**Performance Goals**: Import completes in < 1 second; registry lookup O(1)
**Constraints**: No network I/O at import; no subprocess; no external IP references in any parameter default
**Scale/Scope**: 15 actions at launch; designed to accommodate additions without structural change

## Constitution Check

### Principle I — Safety & Isolation First (NON-NEGOTIABLE) ✅

- All `default_parameters` use `172.28.0.2` (lab-internal); no external IPs.
- `safety_guard()` enforces this structurally — covered by C-010 and C-011.
- No `subprocess`, `socket`, or file I/O at import or definition time — covered by C-015.
- Action definitions are behavioural abstractions, not working exploits.

### Principle II — Reproducibility & Determinism (NON-NEGOTIABLE) ✅

- Registry is a pure, static constant — no randomness at definition time.
- `to_action(timestamp)` is deterministic given the same timestamp; caller injects timestamp.

### Principle III — Pluggable Defence Interface (NON-NEGOTIABLE) ✅ (N/A)

- This feature produces `Action` objects (the input side); the `Defence` interface is the output side. No coupling introduced.

### Principle IV — Scientific Validity & Test-First ✅

- TDD approach: 15 contract tests written before implementation.
- All contracts in `contracts/action-library-contract.md` are covered by tests.

**Gate result: PASS — no violations.**

## Implementation Strategy

### Phase 1 — Baseline & stub (T001–T003)

Record pytest baseline (119 passed, 3 skipped). Create `src/aatf/action_library.py` stub with empty `ActionDefinition`, `ActionRegistry`, `SafetyViolation` and `safety_guard()` that return `[]`.

### Phase 2 — TDD: registry contracts (T004–T018)

Write tests for C-001 to C-008 (registry count, unique IDs, all categories present, get_action, non-empty parameters, description, suricata_category, to_action). Verify red. Implement `ActionDefinition` dataclass, all 15 `ActionDefinition` instances, and `ActionRegistry` with `list_actions()`, `get_action()`, `actions_by_category()`, `to_action()`. Verify green.

### Phase 3 — TDD: safety guard contracts (T019–T026)

Write tests for C-009 to C-015 (to_action fields, safety_guard clean, external IP flag, empty params flag, KeyError, empty-category returns [], no I/O at import). Verify red. Implement `safety_guard()` using `ipaddress` for IP classification. Verify green.

### Phase 4 — Lint & commit (T027–T030)

Run `ruff check --fix`. Run full pytest. Confirm gain of ≥15 new passing tests. Commit.

## Data Flow

```
Action definitions (static)
    └─> ActionRegistry (module-level constant, built at import)
            ├─> list_actions()          → list[ActionDefinition]
            ├─> get_action(id)          → ActionDefinition
            └─> actions_by_category()  → list[ActionDefinition]

ActionDefinition.to_action(timestamp) → Action (F03)
    └─> passed to F08 executor at runtime

safety_guard(REGISTRY) → list[SafetyViolation]
    └─> run in tests; F08 may call at startup
```
