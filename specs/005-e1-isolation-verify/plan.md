## Summary

Promote the F04 isolation guarantee from a manual shell check into machine-verifiable
automated tests that run in `make test`. Three deliverables: (1) a Docker-free pytest test
that parses `lab/docker-compose.yml` and asserts `internal: true`; (2) a new
`src/aatf/isolation.py` module with a fail-closed guard function (`assert_lab_internal`)
that raises `ExternalTargetError` on any externally routable target — tested in pytest
without Docker; (3) a live egress probe test marked `@pytest.mark.docker` that wraps
`lab/scripts/check-isolation.sh` and skips gracefully when the lab is not running.

No new pip dependencies. No changes to `src/aatf/contracts.py` or any existing module.
`make test` remains Docker-free and fast.

## Implementation Phases

### Phase 1: Source module — `src/aatf/isolation.py`

New module with:

```python
class ExternalTargetError(ValueError):
    def __init__(self, target: str, reason: str) -> None:
        self.target = target
        self.reason = reason
        super().__init__(f"External target rejected — {target}: {reason}")

LAB_NETWORKS_DEFAULT = ["172.28.0.0/16"]
_LOOPBACK_NETWORKS = ["127.0.0.0/8", "::1/128"]

def assert_lab_internal(
    target: str,
    allowed_networks: list[str] | None = None,
) -> None:
    """Raise ExternalTargetError if target is not lab-internal or loopback."""
    ...
```

Classification logic (in order):
1. Parse `target` as IP address. If `ValueError`, treat as hostname → resolve with
   `socket.getaddrinfo`. If resolution fails → raise `ExternalTargetError` (fail closed).
2. For each resolved IP: check loopback → pass. Check allowed_networks → pass. Else raise.
3. For multi-address hostnames: ALL addresses must pass (fail if any is external).

### Phase 3: pyproject.toml — register `docker` marker

Add under `[tool.pytest.ini_options]`:
```toml

    "docker: marks tests that require Docker and a running lab (skipped otherwise)",
]
```

This eliminates the `PytestUnknownMarkWarning` when US3 tests run.
