# Implementation Plan: Action Executor (F08)

**Branch**: `011-e2-action-executor` | **Date**: 2026-07-06 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/011-e2-action-executor/spec.md`

## Summary

Build `ActionExecutor` in `src/aatf/action_executor.py` — accepts an `Action` (F03), validates `target_ip` against `172.28.0.0/16` (raises `ExternalTargetError` if outside), dispatches to one of 15 per-`action_id` handlers that emit defanged lab traffic via an injectable `SendFn`, and returns `ExecutionResult`. Timing jitter drawn from a seeded `random.Random`. No new pip dependencies.

## Technical Context

**Language/Version**: Python 3.12 (pinned per F01)
**Primary Dependencies**: stdlib only — `socket`, `http.client`, `random`, `ipaddress`, `struct`, `dataclasses`, `time`; Pydantic V2 (already in `.venv`) for `Action` via F03
**Storage**: N/A — stateless per-call execution; no persistence
**Testing**: pytest (configured); monkeypatch via injectable SendFn/SleepFn
**Target Platform**: Linux (host for unit tests; `aatf-attacker` container for integration)
**Project Type**: Single Python package (`src/aatf/`)
**Performance Goals**: Each `execute()` call < 5 seconds; unit tests < 10ms with no-op sleep
**Constraints**: No raw sockets; no subprocess; no external IP access; injectable send/sleep for test isolation
**Scale/Scope**: 15 action handlers; one executor instance per experiment run

## Constitution Check

### Principle I — Safety & Isolation First (NON-NEGOTIABLE) ✅

- `ExternalTargetError` raised before any traffic for addresses outside `172.28.0.0/16` — structural, not conventional (C-003, C-004, C-005).
- No real exploit payloads — HTTP payloads are benign pattern strings matching ET Open signatures.
- No subprocess calls; no raw socket constructors in production path.
- `SendFn` injectable — unit tests never open real sockets (C-012).

### Principle II — Reproducibility & Determinism (NON-NEGOTIABLE) ✅

- `ActionExecutor(seed)` stores `random.Random(seed)` — same seed = same jitter sequence (C-006).
- `SleepFn` injectable — test execution is instantaneous and deterministic.

### Principle III — Pluggable Defence Interface (NON-NEGOTIABLE) ✅ (N/A)

- Executor is the input side; no coupling to any `Defence` subclass.

### Principle IV — Scientific Validity & Test-First ✅

- TDD approach: 15 contract tests written before implementation.
- Integration test (C-015) auto-skips; does not substitute for real Suricata in reported experiments.

**Gate result: PASS — no violations.**

## Data Flow

```
Action (F03)
  └─> ActionExecutor.execute()
        ├─ [guard] target_ip ∈ 172.28.0.0/16?
        │     NO  → raise ExternalTargetError (no traffic)
        │     YES → continue
        ├─ look up handler by action.action_id
        │     MISS → return ExecutionResult(success=False, emitted_count=0)
        └─ call handler(action, _rng, _send_fn, _sleep_fn) → emitted_count
              └─> ExecutionResult(success=True, emitted_count=N)
```
