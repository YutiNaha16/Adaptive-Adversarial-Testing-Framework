## Summary

Implement `collect_feedback(episode_state, action_id, alert_fired, *, attack_graph=ATTACK_GRAPH, category=None) -> FeedbackResult` in `src/aatf/feedback.py`. ## Architecture

```python
# src/aatf/feedback.py  (complete implementation)
from __future__ import annotations
from dataclasses import dataclass
from aatf.attack_graph import ATTACK_GRAPH, AttackGraph
from aatf.context_vector import EpisodeState


@dataclass(frozen=True)
class FeedbackResult:
    detected: bool
    stage_progress: bool


def collect_feedback(
    episode_state: EpisodeState,
    action_id: str,
    alert_fired: bool,
    *,
    attack_graph: AttackGraph = ATTACK_GRAPH,
    category: str | None = None,
) -> FeedbackResult:
    # Snapshot reachable actions BEFORE mutation (FR-009)
    before_actions = set(attack_graph.available_actions(episode_state.completed_actions))

    # Mutate EpisodeState in-place
    episode_state.alert_history.append(alert_fired)
    episode_state.detection_history.setdefault(action_id, []).append(alert_fired)
    episode_state.completed_actions.add(action_id)
    episode_state.step += 1
    if alert_fired and category is not None:
        episode_state.fired_categories.add(category)

    # Compute stage_progress: any newly reachable actions?
    after_actions = set(attack_graph.available_actions(episode_state.completed_actions))
    stage_progress = bool(after_actions - before_actions)

    return FeedbackResult(detected=alert_fired, stage_progress=stage_progress)
```

## TDD Contracts Summary

10 contracts in `contracts/feedback-contract.md`:
- C-001: alert_history grows by 1 per call
- C-002: detection_history[action_id] list grows per call
- C-003: action_id in completed_actions after call
- C-004: step incremented by exactly 1 per call
- C-005: stage_progress=True when entry point with successors
- C-006: stage_progress=False when terminal node
- C-007: detected=alert_fired in returned FeedbackResult
- C-008: category added to fired_categories when alert_fired=True and category provided
- C-009: fired_categories unchanged when alert_fired=False
- C-010: fired_categories unchanged when category=None
